I built MonitorTool as a practical Windows PowerShell utility to help identify connected monitors and pull useful hardware details like manufacturer, model, and serial number. It was created to make a common IT and support task easier—whether you're tracking inventory, troubleshooting display issues, or documenting assets. The project combines WMI-based device discovery, readable PowerShell output, and a simple Windows Forms interface for quick review, bringing together scripting, systems knowledge, and a focus on making technical tools easier to use.
